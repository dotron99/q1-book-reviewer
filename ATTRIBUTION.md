# Attribution and provenance

This package generalises a book-review workflow: source reading, evidence-led assessment, a journal-specific narrative, red unresolved placeholders and truthful disclosure of assistance. It contains newly prepared generic instructions, scripts and neutral assets. No source book, accepted-review text, publisher artwork or private project records are redistributed.

The neutral Word preset uses a common scholarly layout: A4 pages, one-inch margins, Times New Roman 12 pt, a bibliographic opening and 1.5-spaced review paragraphs. It is not represented as an official template or as a currently endorsed format of any publisher.

OpenAI Codex assisted in preparing the workflow, code, documentation and templates. It does not replace the reviewing scholar or confer authorship of subsequent reviews. No claim is made that all future reviews using this package are human-only work.

The package structure was checked against official OpenAI documentation on 20 November 2026: [Build skills](https://developers.openai.com/plugins/build/skills). This describes a skill directory with `SKILL.md`, a name and description, and optional supporting references, scripts and assets. The package is not affiliated with, endorsed by or an official product of OpenAI or a journal.
