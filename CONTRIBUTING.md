# Contributing

Keep changes focused on observable review quality: correct source attribution, proportionate criticism, accurate provenance, red draft placeholders and reliable document checks.

For code changes, add a test that demonstrates the affected behaviour. Run `python -m unittest discover -s tests -v` and `python scripts/audit_package.py`. If the Word preset changes, render it and inspect every page with a local renderer. Record the method and limitations in the pull request.

Use synthetic fixtures or material with explicit redistribution rights. Do not attach books, private reviews, editorial correspondence, personal information or credentials to issues. For a private issue, use a maintainer contact if the owner has provided one; otherwise report only a redacted description.

Do not describe heuristic scans as comprehensive privacy audits, local formatting checks as journal approval, or model-authored text as independently human-written. Add journal-specific policies only with a dated official source and an explicit scope.
